# CS:GO server plugin

A [Valve server plugin](https://developer.valvesoftware.com/wiki/Server_plugins) loaded into CS:GO when the app starts
the game. It connects to the CS:DM WebSocket server and listens for messages that result in game actions, and executes
the actions file written next to the demo. This file is the developer
documentation.

## Structure

```
csgo-server-plugin/             # This folder
  csgo-server-plugin/           # Sources
    main.cpp, plugin.h          # The plugin: IServerPluginCallbacks, WebSocket messages, actions file
    utils.cpp, utils.h          # Logging and helpers
    cdll_int.h, game_ui.h       # Engine interfaces not in the SDK
    deps/                       # Deps submodules: hl2sdk, easywsclient...
static/                         # Binaries the app installs into the game, built by the CI
  csdm.dll, csdm_client.so, csdm.dylib
  csdm.vdf                      # Plugin manifest the game loads the binary from
```

Paths in this file are relative to this folder, except `src/`, `static/` and `.github/`, which are at the repository
root.

**Never commit locally built binaries.** The committed ones come only from the "Build CS server binaries" GitHub
workflow ([`.github/workflows/build_cs_plugins.yml`](../.github/workflows/build_cs_plugins.yml)), started by hand from the Actions tab, which builds the three
platforms and opens a pull request when they changed. Local builds overwrite the tracked files, leave them out of your
commits.

## Requirements

- **Windows**: [Visual Studio 2026](https://visualstudio.microsoft.com/downloads/) with the component
  `Desktop development with C++`.
- **Linux**: `sudo apt install make build-essential g++`
- **macOS**: `xcode-select --install`

Then fetch the submodules: `git submodule update --init --recursive`. The SDK is the `csgo` branch of
[alliedmodders/hl2sdk](https://github.com/alliedmodders/hl2sdk/tree/csgo), checked out in
[`csgo-server-plugin/deps/hl2sdk`](csgo-server-plugin/deps/hl2sdk).

## Building

### Windows

From a `Visual Studio Developer Command Prompt` in this folder:

```sh
msbuild /p:Configuration=Release /p:Platform=x86 csgo-server-plugin.sln
```

The game is 32-bit on Windows, hence `x86`. The DLL is written to [`static/csdm.dll`](../static/csdm.dll). Building from Visual Studio does
the same.

### Linux

`make build` in [`csgo-server-plugin/`](csgo-server-plugin) writes [`static/csdm_client.so`](../static/csdm_client.so).

### macOS

The game is an `x86_64` binary. On an Apple Silicon Mac, start a shell with that architecture first:

```sh
/usr/bin/arch -x86_64 /bin/zsh --login
```

Then `make build` in [`csgo-server-plugin/`](csgo-server-plugin) writes [`static/csdm.dylib`](../static/csdm.dylib). The Makefile repacks some
prebuilt SDK archives before linking because the linker shipped since Xcode 16 rejects their misaligned members.

## Installation

The app [installs](../src/node/counter-strike/launcher/csgo-server-plugin.ts) the plugin every time it starts CS:GO:

1. The binary and [`csdm.vdf`](../static/csdm.vdf) are copied from [`static/`](../static) to `csgo/addons/` in the game folder. The VDF file is what makes
   the game load the plugin.
2. CS:GO is started with the launch option `-insecure`.

### Uninstallation

The plugin deletes `csdm.vdf` itself when the game starts, so a crash or a game started outside the app doesn't load
it again. The app also deletes the VDF and the binary when the game closes.

## Logging

Logs are printed in the game console with the prefix `CSDM` and written to `csdm.log` in the game's working
directory, `steamapps/common/Counter-Strike Global Offensive/`. The file is cleared when the plugin loads.

## Actions file

The app writes a JSON file next to the demo before starting the playback (`~/myDemo.dem` -> `~/myDemo.dem.json`), a
list of sequences, each a list of actions executed at a tick. It plays the role VDM files had before. The plugin reads
it when the game starts and when the user starts a demo from the app while the game it started is still running.

```ts
type Action = {
  tick: number; // Tick at which the command is executed
  cmd: string; // Game command, for example `demo_gototick 123`
};
```

It is generated by
[`json-actions-file-generator.ts`](../src/node/counter-strike/json-actions-file/json-actions-file-generator.ts) and
read in [`main.cpp`](csgo-server-plugin/main.cpp).

## Updating the SDK

CS:GO no longer receives updates, so this should not be needed. If it is:

1. `git submodule update --remote csgo-server-plugin/csgo-server-plugin/deps/hl2sdk`
2. Rebuild on the three platforms.
